① الخلاصة

دقّقتُ طبقة RBAC/الأمان (قراءة-فقط). التغطية سليمة (0 تجاوز) والـwebhooks موقَّعة. الملاحظة الوحيدة: require_role كان يتجاهل role_status كليًّا — فأصلحتُه بإذنك بقرار محافظ: يحجب الأدوار المنتهية (الموقوفة) فقط، مع إبقاء الإلحاق والاستئناف مسموحَين (لا كسر).

المسح
كلّ مسار مُعدِّل: محروس · public-by-design · أو webhook موقَّع — 0 ثغرة
الإصلاح
require_role يرفض role_status ∈ {SUSPENDED, BANNED, REVOKED, DELETED} (claim فقط، بلا DB)
الأمان
الإلحاق (PENDING_VERIFICATION) + الاستئناف (REJECTED/INACTIVE) يبقيان مسموحَين — لا كسر

② تغطية حُرّاس الأدوار على المسارات المُعدِّلة (المسح)

استعملتُ أداة جرد المسارات لكنّ علمها [AUTH_REQUIRED] heuristic له false-negatives (يُغفل aliases مثل _OPS وrequire_active_role)، فتحقّقتُ مباشرةً من كلّ مسار مشكوك. النتيجة:

الفئةالحالة
محروس (require_role / require_active_role / _OPS …)✅ الغالبيّة
public-by-design (login/register/otp/refresh/totp/password-reset/email-verify — 11)✅ لا يصحّ طلب توكن لتسجيل الدخول
webhook موقَّع (2)✅ راجع §3

0 ثغرة تجاوز — كلّ مسار POST/PUT/PATCH/DELETE مُغطّى.

④ الملاحظة — require_role يتجاهل role_status

الحارسيفحصالاستعمال
require_roleنوع الدور فقط (role_satisfies) — يتجاهل role_statusالخدمة الذاتيّة (كتالوج/ملفّ/وثائق — 57 نقطة)
require_active_roleالنوع + DB: status==ACTIVEالتشغيليّ/الماليّ (قبول/تسليم/نقد/استلام — 38 نقطة)

⇒ مزوّد/سائق موقوف بتوكن صالح كان يستطيع الخدمة الذاتيّة (وإن كانت منخفضة الأثر — كتالوجه مخفيّ وهو موقوف).

⑤ القرار المحافظ — denylist لا allowlist (لماذا)

قِيَم role_status: ACTIVE · PENDING_VERIFICATION · REJECTED · INACTIVE · SUSPENDED. القرار الآمن:

الحالةالقرارالسبب
SUSPENDED · BANNED · REVOKED · DELETEDمحجوبمنتهية — لا تَعمل
ACTIVEمسموحعاديّ
PENDING_VERIFICATIONمسموحالإلحاق (رفع KYC عبر require_role) — لا يُكسَر
REJECTED · INACTIVEمسموحإعادة التقديم/الاستئناف
لماذا denylist محافظ لا allowlist صارم؟ فحص == ACTIVE صارم كان يكسر الإلحاق (مزوّد PENDING_VERIFICATION يحتاج رفع وثائقه قبل الاعتماد). الـdenylist يحجب المنتهي فقط ويترك الإلحاق/الاستئناف يعملان.

⑥ الإصلاح بالكود (dependencies.py)

_BLOCKED_ROLE_STATUSES = frozenset({"SUSPENDED", "BANNED", "REVOKED", "DELETED"})

def require_role(*roles):
    async def _dep(user = Depends(get_current_user)):
        if not role_satisfies(user.role, roles): raise HTTPException(403, "Forbidden")
        if user.role_status in _BLOCKED_ROLE_STATUSES:   # claim الـJWT فقط — بلا DB
            raise HTTPException(403, "الحساب موقوف")
        return user
    return _dep

رخيص (claim الـJWT، بلا استعلام DB)؛ وrequire_active_role يبقى البوّابة الـDB الموثوقة للأفعال التشغيليّة/الماليّة.
