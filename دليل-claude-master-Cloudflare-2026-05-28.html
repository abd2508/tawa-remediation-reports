دليل إنشاء مفتاح claude-master في Cloudflare

التاريخ: 2026-05-28 · الهدف: مفتاح API واحد يَفتح لي كل صلاحيات Cloudflare على دومين tawanow.com · الوقت المتوقّع: 3–5 دقائق

الهدف بسطر واحد
في نِهاية هذا الدليل سيَكون عندك نصّ مكوَّن من ≈40 حرفاً (مثل aBcD-1234567890_efgHIJKLMNopqRSTUVwxyz98). تَنسخه وتُرسله لي، وأنا أَتولّى كل شيء في Cloudflare بعدها — إضافة سجلّات DNS، تَفعيل Email Routing، ربط Resend بالخادم، كل شيء.
1

6
أَرسل لي المفتاح هنا

أَلصقه في رسالة لي. مثال:

هذا مفتاح claude-master:
aBcDeF12-GhIjKlMnOpQrStUvWxYz_3456789012345

وسأَفعل فوراً:

  1. أَختبره مع Cloudflare API للتَأكّد من صحّته (5 ثوانٍ)
  2. أَستخدمه لإضافة كل سجلّات Resend في Cloudflare DNS
  3. أُفعّل Email Routing (لو أردتَ استلام رسائل على info@tawanow.com)
  4. أُحدّث ملفّ الإعدادات على خادم tawanow.com
  5. أُعيد تَشغيل الخلفية
  6. أُخبرك حين يَصبح إرسال OTP الحقيقي جاهزاً

ملحق 1 — أخطاء شائعة وحلولها

الخطأالسببالحلّ
المفتاح بدأ بـ cfk_ أنشأتَ Service Token (للـZero Trust) بدل API Token عادي ارجع للخطوة 2 وتَأكّد من ضَغط «Custom Token → Get started» في قسم API Tokens
المفتاح طوله 37 حرف hex فقط (أرقام وأحرف من a-f) نَسختَ Global API Key القديم هذا مُختلف ويَعمل لكن يَحتاج إيميل حسابك أيضاً. الأَفضل إنشاء API Token حديث (الخطوات 1-5 أعلاه)
الشاشة لا تَعرض زرّ «Create Custom Token» ربما المستخدم Member وليس Owner تَأكّد أنّك تَستخدم حساب صاحب الدومين، لا حساب فريق فرعي
لا أَرى تَبويب «API Tokens» أنت في صفحة Account API بدل Profile API تَأكّد أنّ الـURL بالضبط: dash.cloudflare.com/profile/api-tokens

ملحق 2 — كيف أَستخدم المفتاح (لِعِلمك)

عندما يَصلني المفتاح، سأَستعمله بشكل آمن في Cloudflare API كهذا:

curl -H "Authorization: Bearer YOUR_TOKEN" \
     -H "Content-Type: application/json" \
     "https://api.cloudflare.com/client/v4/zones/1915062b57c2667ee8936fed9fff702b/dns_records" \
     -X POST -d '{
       "type": "TXT",
       "name": "send.tawanow.com",
       "content": "v=spf1 include:amazonses.com ~all",
       "ttl": 300
     }'

ثم أُضيف 2 سجلّ آخر (CNAME + TXT DMARC) بنفس الطريقة، وهكذا تَنتهي العملية.

ملحق 3 — أَمان المفتاح

  • المفتاح حصريّ لدومين tawanow.com فقط (لو شملتَ زون واحد) — لا يُمكنه الوصول لأي حساب آخر
  • الصلاحيات مَحدودة بـ4 أشياء (DNS، Zone Settings، Email Routing × 2) — لا يُمكنه حذف الدومين أو الفوترة أو التَطبيقات
  • بعد انتهاء عملنا (تَفعيل Resend ناجح)، يُمكنك حذف المفتاح فوراً من نفس الصفحة (dash.cloudflare.com/profile/api-tokens)
  • المفتاح ليس مُخزَّناً في أي ملف داخل المشروع — يُستعمل في ذاكرة الجلسة فقط
الخلاصة
3 ضغطات زرّ في Cloudflare (Create Token → Custom Token → Get started) + إضافة 4 صفوف أذونات + اختيار tawanow.com = مفتاح يَفتح لي كل ما أحتاج. بعدها أنا أَتولّى Cloudflare بنفسي ولن تَلمسه مرّة أخرى.

ولا تَنسَ: Resend خدمة مُنفصلة تَتطلّب تَسجيلك ببريدك الشخصي (دقيقتان منك) ثم تُعطيني مفتاح Resend وأَفعل الباقي.
