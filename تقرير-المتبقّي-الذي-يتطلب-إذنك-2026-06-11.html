٢. الفئة أ — تحسينات التنقّل الاختياريّة واجهة · منخفضة المخاطر

أ-1 · Priority+ (طيّ الأقسام الفائضة في «المزيد») جهد: متوسّط

الآن صفّ الأقسام (Tier 1) يُمرَّر أفقيًّا عند ضيق الشاشة (MVP، القرار SIM-RESP-1). البديل الأرقى: قياس ما يسع وطيّ الفائض تلقائيًّا في قائمة «المزيد ⋯» (نمط Priority+).

🔑 لماذا يحتاج إذنك: ليس عيبًا — التمرير يعمل؛ هذا ترقية UX اختياريّة. كما أنّ Priority+ يتطلّب ResizeObserver + قياسًا ديناميكيًّا (أعقد وأهشّ قليلًا)، فأردتُ موافقتك قبل إضافة التعقيد.

الآن (تمرير أفقيّ): [⭐][🕘][🧭 الرئيسية][🏢 الكيانات][🍽️…] ‹‹ تمرير ›› ⋯ Priority+ (مقترح): [⭐][🕘][🧭 الرئيسية][🏢 الكيانات][💵 المالية] [⋯ المزيد ▾] └ الباقي يُطوى تلقائيًّا

المخاطر: منخفضة (واجهة). توصيتي: تأجيل — التمرير كافٍ؛ نضيفه إن لزم على شاشات صغيرة كثيرة.

أ-2 · إخفاء Tier 2 عند التمرير لأسفل جهد: منخفض

الطبقتان تستهلكان صفّين علويّين. عند تصفّح جدول طويل يمكن إخفاء صفّ العناصر (Tier 2) تلقائيًّا عند التمرير لأسفل وإعادته عند التمرير لأعلى — لاسترجاع ارتفاع للمحتوى (SIM-VSPACE-1).

🔑 لماذا يحتاج إذنك: يغيّر سلوك ظهور التنقّل أثناء التصفّح (قد يفاجئ بعض المشغّلين). قرار تجربة، لا إصلاح.
تمرير لأسفل ▼ : [top-bar] + [Tier1 الأقسام] ← Tier2 يختفي، مساحة أكبر للجدول تمرير لأعلى ▲ : [top-bar] + [Tier1] + [Tier2 العناصر] ← يعود

المخاطر: منخفضة. توصيتي: اختياريّ — مفيد على الشاشات القصيرة.

أ-3 · توسيع الشارات الحيّة لعناصر أخرى جهد: منخفض

الآن الشارات تغطّي عنصرين: الاعتماد المعلّق (18) والشكاوى المفتوحة (1). يمكن توسيعها لِـ: استثناءات النقد · الطلبات بلا سائق (orders_without_driver_now من live-kpis) · طوارئ السائقين · الحوادث المفتوحة.

🔑 لماذا يحتاج إذنك: كلّ شارة = استدعاء API دوريّ إضافيّ (حِمل خفيف). أردتُ موافقتك على أيّ العدّادات تريد إبرازها (لتجنّب ضجيج/حِمل غير مرغوب).

المخاطر: منخفضة (fail-open، لا شارة عند الخطأ). توصيتي: ضمّ «استثناءات النقد» و«الطلبات بلا سائق» (إشارات تشغيليّة عالية القيمة).

٣. الفئة ب — ميزات التحسينات المؤجَّلة بقرارك (E) سياسة/تصميم/تبعية

ب-1 · تفعيل E1 — سياج التسوية الجغرافيّ جهد: تفعيل فقط

الكود منشور حيًّا لكنّه خامل: config.py:119 settlement_geofence_alert_km = 0 (0 = معطّل). عند ضبطه > 0 يبدأ بوضع علامة GEO_FAR + تنبيه على أيّ تحقّق مندوب بعيد جغرافيًّا (دون حجب).

🔑 لماذا يحتاج إذنك: قراران لك — (1) هل نفعّل أصلًا؟ (2) ما عتبة المسافة بالكيلومتر؟ (مثلاً 5 كم). تغيير سلوك تشغيليّ على الإنتاج → بإذنك.

المخاطر: منخفضة (استشاريّ، fail-open). توصيتي: فعّله بعتبة محافظة (مثلاً 10 كم) لمراقبة الإشارات أولًا.

ب-2 · E3 — هيكل «المندوب الرئيس» (Master-Agent) جهد: كبير

تنظيم هرميّ للمندوبين (مندوب رئيس يشرف على مندوبين فرعيّين، عوائم/حدود متدرّجة). إستراتيجيّ.

🔑 لماذا يحتاج إذنك: يتطلّب migration قاعدة بيانات + تصميم صلاحيّات هرميّ + مساس بمنطق التسويات. منطقة حسّاسة (مال) — يحتاج إذنًا صريحًا + قرارات تصميم.

المخاطر: متوسّطة–عالية. توصيتي: تأجيل حتّى تتّضح الحاجة التشغيليّة؛ يبدأ بجلسة تصميم مستقلّة.

ب-3 · E5 — تحقّق الوثائق + كشف الحياة (Liveness/AI) جهد: كبير

تحقّق آليّ من وثائق KYC + كشف حياة (صورة حيّة لا صورة-لصورة) عبر ذكاء اصطناعيّ.

🔑 لماذا يحتاج إذنك: يتطلّب مزوّد خدمة/نموذج ذكاء خارجيّ (تكلفة + اختيار مورّد + خصوصيّة بيانات). قرار مشتريات/معماريّة لك.

المخاطر: عالية (تبعية خارجيّة + خصوصيّة). توصيتي: تأجيل لمرحلة لاحقة؛ يُربط بقرار مزوّد الدفع/الخرائط الإستراتيجيّ.

ب-4 · E7 — افتراضية الجداول/القوائم الطويلة (Virtualization) جهد: متوسّط

عرض الصفوف المرئيّة فقط في الجداول الكبيرة (أداء أسرع، ذاكرة أقلّ) عبر نافذة افتراضيّة.

🔑 لماذا يحتاج إذنك: أُجِّل بقرار SIM-E7-1 (القوائم الحاليّة صغيرة والبطاقات متغيّرة الارتفاع/قابلة للتوسّع، فالافتراضية قد تعقّد دون فائدة الآن). نضيفه إن كبرت البيانات.

المخاطر: منخفضة–متوسّطة. توصيتي: تأجيل حتّى تظهر جداول تتجاوز مئات الصفوف فعلًا.

٤. الفئة ج — بوّابة حوكمة إلزاميّة (يجب سؤالك صراحةً) حوكمة

ج-1 · عزل OPS بنطاق فرعيّ — ops.tawanow.com جهد: كبير

الآن لوحة OPS معزولة بالمسار (/ops، بناء Vite منفصل — مكتمل بالمرحلة 377). البديل: عزلها بنطاق فرعيّ مستقلّ ops.tawanow.com.

🔑 لماذا يحتاج إذنك (بوّابة إلزاميّة): مسجَّلة في الحوكمة كـGATE-OPS-C03-R04 — «بوّابة قرار إصدار مستقبليّ يجب رفعها للمالك صراحةً قبل أيّ عمل، ولا تُنفَّذ من طرف واحد». تتطلّب: nginx vhost منفصل + DNS + شهادة TLS + إعداد CORS/مصادقة عبر-النطاقات + لمس docker-compose.yml (منطقة محظورة).
الآن (مسار): tawanow.com/ops ← بناء OPS منفصل (مكتمل، آمن) المقترح (نطاق): ops.tawanow.com ← vhost + DNS + TLS + CORS + docker-compose (عزل أقوى، لكنّه بنية تحتيّة + منطقة محظورة)

المخاطر: عالية (بنية تحتيّة + منطقة محظورة + مصادقة عبر-النطاقات). الحالة: اختياريّ — ليس حاجبًا (العزل بالمسار يكفي). توصيتي: لا حاجة الآن؛ يُرفع فقط إن قرّرت تشديد العزل لإصدار مؤسّسيّ.
