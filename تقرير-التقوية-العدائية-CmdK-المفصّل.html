② F1 — بحث الأشخاص كان يُظهر أدوارًا بلا كونسول عيب UX

بحث الأشخاص في ⌘K أداة قفز إلى كونسول الكيان، والكونسولات موجودة فقط لـعميل/مزوّد/سائق. لكنّ searchUsers(q) بلا دور يُرجع كلّ الأدوار (incl. OPS/SUPER/FINANCE)، واختيار أحدهم كان يُعمِّق إلى كونسول العملاء (طريق مسدود — لا يُوجد هناك). الإصلاح: فلترة النتائج للأدوار القابلة للانتقال. 

setPeople(
  (res.data as PersonResult[])
    .filter((p) => /CUSTOMER|PROVIDER|DRIVER/.test((p.role || "").toUpperCase()))
    .slice(0, 6),
);

③ F2 — التعميق لا يتفاعل إن كان المشغّل أصلًا على الكونسول عيب حدّيّ

عند اختيار شخص، تُعمِّق اللوحة إلى /ops/cp/{role}?q=<phone>. تأثير قراءة ?q في الكونسولات كان useEffect(…, []) (mount-only). إذا كان المشغّل أصلًا على نفس الكونسول، فتغيّر الـquery لا يُعيد التركيب (نفس عنصر المسار) ⇒ التأثير لا يُعاد ⇒ لا بحث مسبق. الإصلاح: اشتقاق q تفاعليًّا عبر useSearchParams وجعله ضمن اعتماديّات التأثير. 

- const dq = new URLSearchParams(window.location.search).get("q");
- useEffect(() => { if (dq…) handleSearch(dq); }, []);
+ const [deepLinkParams] = useSearchParams();
+ const deepLinkQ = deepLinkParams.get("q");
+ useEffect(() => {
+   if (deepLinkQ && deepLinkQ.trim().length >= 3) { setPageTab("search"); handleSearch(deepLinkQ.trim()); }
+ }, [deepLinkQ]);   // يتفاعل مع تغيّر ?q (Customers بلا setPageTab)

④ أثر F2 على الاختبارات — سياق Router (التقطه التحقّق)

الإصلاح كسر اختبارات الكونسولات: useSearchParams يتطلّب سياق <Router>، واختبارات الكونسولات تُصيِّرها مستقلّة ⇒ useLocation() may be used only in the context of a Router. الحلّ النظيف: vi.mock("react-router-dom", …) يُرجع useSearchParams فارغًا في اختبارات الكونسولات الثلاثة (لا تختبر التعميق) — بدل تغليف ~18 نداء render بـMemoryRouter. 
vi.mock("react-router-dom", () => ({
  useSearchParams: () => [new URLSearchParams(), vi.fn()],
}));

⑤ F3 — التحقّق الخارجيّ متزامن في طلب الرفع ملاحظة تفعيل

queue_document_verification يجري داخل طلب رفع الوثيقة. للمُحوِّل المحلّيّ (داخل العمليّة) ذلك ضئيل، لكنّ المُحوِّل الخارجيّ يجري نداء شبكة (≤doc_verify_timeout_seconds) ⇒ عند تفعيله يضيف زمنًا لاستجابة الرفع. المسار خامل، فلم أبنِ بنية async تخمينيّة؛ بل وُثِّق صراحةً كملاحظة تفعيل في external_doc_adapter.py: نقل النداء خارج الطلب (commit الوثيقة ثمّ تشغيل التحقّق في BackgroundTask يُحدِّث الصفّ) قبل التشغيل الحيّ.
