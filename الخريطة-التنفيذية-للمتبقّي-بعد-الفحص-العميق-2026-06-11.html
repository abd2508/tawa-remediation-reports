أ-1 · Priority+ (طيّ الفائض في «المزيد») جهد: متوسّط

  3. اختبار: حاوية ضيّقة → تبويبات الفائض في «المزيد».

٤. الموجة 2 — تفعيل E1 (السياج الجغرافيّ) تفعيل + قرار عتبة

  2. (اختياريّ) صفحة/فلتر OPS تعرض معاملات التسوية المعلَّمة GEO_FAR في الملاحظات + التنبيهات settlement.geofence_far.

٥. الموجة 3 — الإستراتيجيّ بوّابات قرار

ب-4 · E7 الافتراضية — مُحدَّثة بتقنية 2026 جهد: منخفض الآن

💡 تبسيط جوهريّ: بدل إضافة مكتبة افتراضية، نستخدم CSS content-visibility: auto + contain-intrinsic-size على صفوف الجداول — أصليّ، بلا تبعيّة، Baseline 2025، ويعطي ~90% من الفائدة لمئات الصفوف (مقياس جداول OPS). فقط لو تجاوز جدول ~1000 صفّ فعليًّا نضيف @tanstack/react-virtual (يتناغم مع react-query الموجودة).
  1. قاعدة CSS عامّة لصفوف جداول OPS الكبيرة: content-visibility:auto; contain-intrinsic-size: 0 44px;.
  2. تطبيق على المرشّحات: OpsLedgerExplorer · OpsReconciliation · ControlPanelUsers/Providers/Drivers/Customers.
  3. قياس: تحسّن وقت التصيير على جدول كبير (Profiler) قبل/بعد.

ب-2 · E3 المندوب الرئيس (Master-Agent) جهد: كبير · migration

  1. migration: عمود parent_agent_id (FK ذاتيّ، nullable) على settlement_agents + فهرس.
  2. منطق: تجميع عوائم/حدود الفرعيّين تحت الرئيس · تسويات متدحرجة · حُرّاس صلاحيّة.
  3. واجهة OPS: شجرة المندوبين + إسناد فرعيّ.
🔑 بوّابة: migration + منطق ماليّ → جلسة تصميم + إذن صريح. قرارات: ماذا يتحكّم به «الرئيس»؟ تجميع العائم؟ موافقات؟

ب-3 · E5 تحقّق الوثائق + Liveness/AI جهد: كبير · مزوّد

  1. ربط مزوّد PAD/liveness عند approve_document: قراءة الصورة من MinIO (object_key) → درجة تحقّق تُخزَّن وتُعرَض في واجهة الاعتماد.
  2. تقنية 2026 (NIST SP 800-63-4): liveness سلبيّ (بلا احتكاك) + معالجة هجمات العرض والحقن معًا. مرشّحو مورّدين: Incode (iBeta L3 2026)/Paravision/FaceMe/ID-Pal.
  3. قرار على-الجهاز مقابل سحابيّ (خصوصيّة/تكلفة).
🔑 بوّابة: اختيار مورّد + قرار خصوصيّة بيانات + تكلفة. يُربط بقرارات المشروع الإستراتيجيّة (دفع/خرائط).

ج-1 · عزل OPS بنطاق فرعيّ جهد: كبير · أمن/بنية

المطلوب لو نُفِّذ: 1) backend: auth_cookies.py + domain=".tawanow.com" ← يكسر host-only الحاليّ 2) مشاركة device_id عبر النطاقات (localStorage per-origin) ← إعادة تصميم 3) nginx: server{ server_name ops.tawanow.com } + DNS A + شهادة TLS 4) CORS + docker-compose.yml (منطقة محظورة)
🔑 تحذير أمنيّ 2026 (مؤكَّد بالبحث): توسيع نطاق الكوكي للجذر يُرسل كوكي SSO لكلّ النطاقات الفرعيّة → أيّ نطاق فرعيّ مُخترَق يكشف كلّ الجلسات (وسم __Host- يمنع المشاركة عمدًا). توصيتي القويّة: الإبقاء على العزل بالمسار /ops (مكتمل وآمن) — لا تنفيذ.
