1

المرحلة ١ — التصليب الأمني

PR #6 ✓
CR-05إخفاء تفاصيل الأخطاء عن المستخدم

تعقيم مركزي (معيار RFC 9457): أخطاء النظام الداخلية لا تُظهر تفاصيلها للعميل في الإنتاج (رسالة عامة + رقم تتبّع في السجلّ)، وتبقى التفاصيل في بيئة التطوير.

CR-04إغلاق باب لوحة المشرف افتراضياً

بوّابة fail-secure متدرّجة: يرفض النظام الإقلاع في الإنتاج لو كانت قائمة عناوين المشرف المسموحة فارغة (بعد أن يفعّلها المالك) — بلا كسر الخوادم الحالية.

E-034عدم إسناد سائق حظره العميل

قائمة الحظر صارت 3-حالات مع ذاكرة مؤقّتة: لو فشل الفحص والذاكرة باردة، يُؤجَّل الطلب الواحد بدل إسناد سائق محظور — دون تجويع الأسطول (نمط Uber CacheFront).

2

المرحلة ٢ — الصلاحيات ومنع التكرار

PR #7 ✓
CR-06صلاحيات الموظّف: من «الدور» إلى «إذن»

5 نقاط تشغيل المتجر (فتح/إغلاق/إيقاف) صارت بإذن مُحدّد قابل للإلغاء من المالك، مع بقائها متاحة لكل الموظّفين افتراضياً — بلا حجب ولا هجرة.

CR-08توحيد منع تكرار العمليات + عيبان حيّان

🐞 عيب 1: النظام كان يخزّن استجابات الأخطاء (5xx) ويُعيدها ٢٤ ساعة — أُصلح (2xx فقط). 🐞 عيب 2: الشكوى كانت تفبرك مفتاحاً عشوائياً → شكاوى مكرّرة — أُصلح (مفتاح ثابت).

3

المرحلة ٣ — الجودة والوثائق

PR #8 ✓
F821🐞 عيب حقيقي: إشعارات لا تُسلَّم

دالّة `_dispatch_notification` كانت مُستدعاة لكن غير معرّفة — كل إشعار في الطابور كان يفشل ويُهمَل. نُفّذت بشكل صحيح.

CR-01جعل فحص الجودة إلزامياً تدريجياً

quality ratchet: أي كود جديد يجب أن يكون نظيفاً (حاجب)، والمتراكم القديم يُورَّث ويُنظَّف تدريجياً — أفضل ممارسة عالمية.

CR-10توحيد رقم إصدار الوثائق

حُسم الرقم المعتمد = R18.8-LY (أُصلح انجراف R18.3 و R18.12) + وثيقة مصدر واحد + فحص CI يمنع الانجراف مستقبلاً.

المرحلة ٤ — المعمارية

PR #9 ✓
CR-07فصل المهام الخلفية عن خادم الواجهة

عَلَم `RUN_BACKGROUND_JOBS` يُبوّب الـ16 مهمّة خلفية — يُمكّن تشغيل عدّة نسخ من الخادم بلا تكرار المهام (أساس التوسّع الأفقي). افتراضي: بلا تغيير.

المرحلة ٥ — الحوكمة

PR #9 ✓
CR-03🐞 عيب أمني خطير: فحص FIN-COR كاذب النجاح

قارئ العَلَم كان لا يزيل التعليق، فيقرأ «true # ملاحظة» كأنه false — **كان يُخفي انقلاب عَلَم مالي مختوم!** أُصلح بـyaml.safe_load؛ الفحص الآن يكشف الانقلاب فعلاً.

CR-02إغلاق بوّابات الإطلاق بالأدلّة

فحص جاهزية آلي (٧ بوّابات حاجبة مفتوحة → غير جاهز) + مصفوفة أدلّة — دعم كودي بلا مساس بعقود FIN-COR.
