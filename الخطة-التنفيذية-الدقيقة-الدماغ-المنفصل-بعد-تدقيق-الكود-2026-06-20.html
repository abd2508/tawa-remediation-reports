٢ أحدث التقنيات — ماذا نضيف (فحص إنترنت 2026)

بلغة بسيطة: بحثنا عن أحدث الأدوات المجرَّبة عالميًّا في 2026، فوجدنا خمسًا تجعل الدماغ أقوى وأأمن — أدرجناها في الخطّة بمواضعها.
🆕 ① Redis Streams بدل pub/sub للتغذية الدائمة[8]: الـpub/sub الحاليّ يفقد الرسائل لو كان الدماغ منقطعًا/بطيئًا؛ Redis Streams دائم (consumer groups + ack + replay) فلا يفوت الدماغ حدثًا عند عودته. أين: التغذية اللحظيّة في feeds/redis_sub.py + الناشر يكتب Stream مرآةً للقناة. (الـOutbox يبقى للأحداث المضمونة.)
🆕 ② River — تعلّم متدرّج حيّ + كشف انحراف[9]: مكتبة Python تتعلّم عيّنة-بعيّنة دون إعادة تدريب كامل، وتكشف «انحراف المفهوم» (تغيّر أنماط الاحتيال) بـADWIN/PageHinkley فتنبّه لإعادة التدريب. مثاليّة لاحتيال يتغيّر بسرعة. أين: training/online.py لوكيل الاحتيال (P2).
🆕 ③ NannyML / Evidently — مراقبة انحراف النموذج[10]: NannyML يقدّر أداء النموذج دون معرفة النتيجة الحقيقيّة بعد (CBPE/DLE) — مثاليّ لاحتيالنا (الوسم يتأخّر حتى التسليم). Evidently يولّد تقارير انحراف بصريّة. أين: training/monitoring.py + يكتب تنبيهًا عبر alert_webhook (P2/P3).
🆕 ④ Phi-4-mini نموذجًا للوكيل النصّيّ[2]: أفضل نموذج صغير 2026 (3.8B، ~3GB، نافذة 128K، أمر تثبيت واحد عبر Ollama، يعمل على CPU حديث). بدائل: Gemma 3 (صور)، SmolLM3 (رخصة مفتوحة)، Qwen3 (كود). أين: agents/triage.py + GGUF Q4_K_M/llama.cpp (P4).
🆕 ⑤ pybreaker — قاطع الدائرة[3]: مكتبة Python ناضجة لحالات مغلق/مفتوح/نصف-مفتوح (غير موجودة في كودنا). أين: integrations/tic_client.py (P0) — أو تطبيق خفيف بعدّاد Redis.

٣ العقد الدقيق — tic_client.py (الباب الوحيد المرن)

مُشتقّ حرفيًّا من geo_providers.py + بوّابة ai_features_toggle + قاطع دائرة جديد:
// backend/app/integrations/tic_client.py (يُنشأ في P0 — الوحيد الذي يكلّم الدماغ) import httpx from app.config import settings from app.core.ai_features_toggle import is_ai_auto_enabled from app.integrations._breaker import breaker // قاطع دائرة جديد (Redis-backed) async def score(task: str, payload: dict) -> dict | None: if not settings.tic_url: return None // مُعطَّل (نمط osrm_base_url فارغ) if not await is_ai_auto_enabled(): return None // بوّابة Redis لحظيّة (fail-safe) if await breaker.is_open(task): return None // قاطع الدائرة مفتوح → تخطٍّ فوريّ try: async with httpx.AsyncClient(timeout=settings.tic_timeout) as c: // مهلة من config r = await c.post(f"{settings.tic_url}/tic/{task}", json=payload) if r.status_code != 200: await breaker.fail(task); return None await breaker.ok(task); return r.json() // {engine, model_version, confidence, ...} except (httpx.HTTPError, ValueError, KeyError, TypeError): // التقاط ضيّق (نمط geo_providers) await breaker.fail(task); return None // → المُستدعي يرجع لقاعدته
// إضافات app/config.py (بجوار كتلة self-hosted maps، ~210) tic_enabled: bool = False // للتوثيق/التكامل المستقبليّ tic_url: str = "" // فارغ = مُعطَّل → fail-open tic_timeout: float = 0.15 // 150ms — لا ينتظر المشروع أكثر tic_breaker_threshold: int = 5 // فشل متتالٍ يفتح القاطع tic_breaker_cooldown: float = 30.0 // ثوانٍ قبل نصف-مفتوح
لماذا هذا يحقّق «لو انقطع لا يتأثّر المشروع»: كلّ المسارات الثلاثة (علَم/بوّابة/قاطع) ترجع None فورًا دون شبكة؛ وحتى عند النداء، المهلة 150ms تقطع أيّ بطء؛ وأيّ استثناء يُلتقَط ويُرجِع None. المُستدعي دائمًا: tic_client.score(...) or <القاعدة الحاليّة>.

P2 أوّل نموذج مدرَّب + التعلّم الحيّ + المراقبة (مخاطرة متوسّطة — وضع الظلّ)

  • runtime/onnx_runner.py — تحميل/تشغيل ONNX ≤50ms · registry/ ملفّ+إصدار+تراجع
  • 🆕 training/online.py — River تعلّم متدرّج + كشف انحراف (ADWIN/PageHinkley)[9]
  • 🆕 training/monitoring.py — NannyML/Evidently تقدير أداء دون وسم + تنبيه انحراف عبر alert_webhook[10]
  • وضع الظلّ: البطل=القاعدة يُطبَّق؛ المتحدّي=النموذج يُسجَّل في SystemEvent ويُقارَن offline؛ ترقية ببوّابة holdout + تراجع تلقائيّ[7]
معيار الإنجاز: المتحدّي يتفوّق على البطل في holdout (AUC↑) قبل أيّ ترقية · لا تأثير على القرار الحيّ أثناء الظلّ.

  • منتجات تتغذّى: خريطة طلب السائق · مكافآت ذروة آليّة · «الأكثر طلبًا» (ربط لا بناء)
معيار الإنجاز: مقاييس ETA/التوزيع تتحسّن في الظلّ · لا فقدان أحداث عند إعادة اتّصال الدماغ (Streams).

P4 الوكيل النصّيّ + جدار PII + (اختياريّ) الباب الخارجيّ (مرحليّة)

  • 🆕 agents/triage.py — Phi-4-mini (GGUF Q4_K_M/llama.cpp) خلف طابور غير حاجب[2]: مسوّدة حادثة + ملخّص ورديّة + تصنيف شكوى
  • pii/redact.py — Presidio (PII Shield) يُخفي الأسماء/الهواتف قبل أيّ نموذج خارجيّ[4]
  • الباب الخارجيّ (LLM سحابيّ) مُغلق حتى DPA + إقرار خصوصيّة (نمط doc_verify_external_privacy_ack)
