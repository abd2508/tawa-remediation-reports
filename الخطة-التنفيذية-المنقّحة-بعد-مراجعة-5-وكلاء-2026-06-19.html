③ بنود قاعدة البيانات — مُصحَّحة بعد المراجعة

P1-B فهرسة الـFK غير المفهرسة 🟢 افعل (مُصحَّح)
حاجز مُصحَّح: لا CREATE INDEX CONCURRENTLY (يُفشِل النشر داخل ترانزاكشن الإقلاع — ✓ مُتحقَّق). استعمل CREATE INDEX IF NOT EXISTS بأسماء صريحة + de-dup مقابل الفهارس المركّبة القائمة (الصافي الجديد أقلّ من 43). wallet_transfers.sender/receiver_wallet_id ناقصان فعلًا. أقلّ مخاطرة ⇒ أوّلًا.
P1-A JSON→JSONB 🟠 افعل بنطاق ضيّق (مُصحَّح جذريًّا)
خطأان في الخطّة الأصليّة: (1) شكل الفهرس خاطئ — الاستعلام similarity(arabic_normalize(display_name->>'ar')) = trigram ⇒ يحتاج GIN pg_trgm على arabic_normalize(col->>'ar') (نمط aa08) لا btree تعبيريّ. (2) النطاق 24× واسع — فقط عمودان يُستعلَمان بالمسار (providers.display_name+catalog_items.names_json)؛ الـ47 الباقية بلا فائدة استعلام. خطر: ALTER ... USING ::jsonb = إعادة كتابة كاملة بقفل ACCESS EXCLUSIVE وقت الإقلاع + يفشل على صفوف بمفاتيح json مكرّرة ⇒ افحص مسبقًا. ⇒ حوّل العمودين فقط + GIN trgm.
P1-C حذف الأعمدة الميّتة (status/version) 🟢 افعل (آمن)
مؤكَّد 0 قراءة. حذف العمودين + إزالة كتابات version الـ7. هجرة drop_column + رجعة اختبارات المحفظة.
P1-D WAL/PITR + pg_stat_statements 🟢 افعل (تشغيليّ)
تفعيل أرشفة WAL (الإعداد جاهز) + pg_stat_statements للرصد. إعادة تشغيل postgres واحدة. لا هجرة.
P2-A قيد قاعدة لتوازن الدفتر 🟢 افعل (مؤكَّد آمن — D1)
CONSTRAINT TRIGGER ... DEFERRABLE INITIALLY DEFERRED (لا CHECK-بـsubquery — غير صالح PG)، يفحص Σ(debit-credit)=0 per journal_id عند commit، يعالج DELETE بـCOALESCE(NEW,OLD).journal_id. كلّ الـ32 مستدعيًا متوازن ⇒ لا يرفض شيئًا قائمًا. PG-only (op.execute no-op على SQLite) + يبقى الحارس البايثوني (الوحيد في الاختبارات + خطأ 422 نظيف) + اختبار PG.
P2-D تفعيل الـoutbox القائم 🟠 افعل (مُعاد هيكلته — D3)
EventOutbox سقالة ميّتة (صفر كاتب/مستنزِف). التفعيل: (أ) كتابة الحدث داخل ترانزاكشن العمل (ضمان durable). (ب) _outbox_relay_loop (نمط الـ12 حلقة، SweepSessionLocal/NullPool، قفل Redis، FOR UPDATE SKIP LOCKED). at-least-once (Redis pub/sub بلا ack) ⇒ مستهلكون idempotent. أضِف: سقف retry+backoff+dead-letter (وإلّا صفّ سامّ يدور أبدًا) + فهرس جزئيّ WHERE published_at IS NULL (الحاليّ يتضخّم).
P2-B حارس Σ المحفظة الحيّ 🟠 رحّله (مُصحَّح — D1)
الكود نظيف، لكن docstring الذي كتبتُه يحذّر أنّ أرصدة البذور/التاريخيّة بلا قيد ⇒ إنذار كاذب؛ وحارس عالميّ صارم = تعطيل كلّ عمليّات المحافظ (مجموع عالميّ، لا يعرف أيّ محفظة). التسلسل: (1) شغّل الفحص على القاعدة الحقيقيّة ⇒ diff==0؛ إن لا، backfill journal. (2) فحص مجدول يفتح ReconciliationException (config-gated). (3) لاحقًا فقط حارس per-wallet على مسار الكتابة — لا inline عالميّ.
P2-C التقسيم الزمنيّ 🔴 أجِّل/ارفض كما هو (مُصحَّح — D2)
4 حواجز حرجة: (1) created_at ليس في PK لكلّ الجداول الـ7 (✓ مُتحقَّق) ⇒ تغيير PK كاسر. (2) تحويل جدول مأهول = copy-swap لا يعمل في ترانزاكشن الإقلاع. (3) pg_partman/pg_cron يحتاجان superuser+shared_preload_libraries+restart — مستحيل من هجرة. (4) ledger_entries تجميعاته بلا created_at ⇒ يفقد pruning + قلب FIN-COR ⇒ يُستثنى إلزاميًّا. + retention_service (مرحلة 171) يحلّ النموّ. ⇒ إن نُفِّذ: خارج النطاق، بإدارة المشغّل، باستثناء ledger_entries.
P3-A ترقية PG 16→17→18 🟢 افعل (منخفضة — D3)
فقط pg_trgm+plpgsql. الترقية القياسيّة + REINDEX فهارس trgm الثلاثة (نمط aa08 موجود) + collation. 18: async I/O 3× + skip-scan. تسلسل: إن أُضيف pgvector/PostGIS أوّلًا ⇒ ثنائيّات مطابقة الإصدار.
P3-D pgvector (ذكاء الاحتيال/التوصيات) 🟠 افعل إضافيًّا (مُصحَّح — D3)
جدول منفصل entity_embeddings (لا تمسّ signals_json/fraud_flags)؛ المحرّك القاعديّ يبقى الحَكَم؛ بوّابة ai_features_toggle. يحتاج: تبديل صورة (pgvector/pgvector:pg16 — محظورة) + فرع SQLite + نموذج تضمين (غير موجود) عبر حلقة sweep.
P3-C PostGIS للمكان 🟠 ثانويّ/مُصحَّح (D3)
كتابة-مزدوجة geometry (أبقِ JSON مصدرًا)؛ خطر انعكاس lat/lng (ST_MakePoint(lng,lat) بينما المخزّن [lat,lng])؛ فرع SQLite؛ تبديل صورة (محظورة)؛ Redis GEOSEARCH يحلّ أقرب-سائق أصلًا (نقله سلبيّ). مكسب هامشيّ بمقياس التجربة.
P3-E RLS + pgcrypto 🔴 RLS أجِّل / pgcrypto انتقائيّ (مُصحَّح — D3)
RLS حاجز عالٍ: الجلسة لا تعرف المستخدم (get_db≠get_current_user) + superuser (يتجاوز RLS) + OPS/sweeps تقرأ عبر المستخدمين ⇒ يحجبها. يحتاج: دور غير-مالك + SET LOCAL لكلّ-طلب-ترانزاكشن + BYPASSRLS لـOPS/sweeps ⇒ تغيير معماريّ، مكسب هامشيّ (ABAC قائم). pgcrypto لحقول PII مختارة (أخفّ).
P3-B / P3-F PgBouncer+نسخة قراءة / تقييم uuid 🟡 لاحقًا / تقييم
PgBouncer+replica عند النموّ (بنية تحتيّة، فصل قراءة/كتابة). uuid أصليّ بدل varchar(36): تقييم لا تنفيذ (هجرة ضخمة عالية المخاطر).
