٥) موثوقيّة تحديث الـPWA — لماذا لا تظهر التعديلات + الحلّ

🟦 الجذر الفعليّ: الإعداد الحاليّ autoUpdate لكن لا يوجد فحص تحديث دوريّ (registration.update()) — فالتبويب المفتوح طويلاً (تطبيق السائق طوال الوردية) لا يكتشف النشر حتى ~24 ساعة (فحص المتصفّح الافتراضيّ). هذا سبب عدم ظهور أيقونة الخريطة. (+ احتمال تخزين CDN لـsw.js.)
دورة حياة الـService Worker: installing → waiting → activating → activated المتصفّح يكتشف SW جديداً فقط حين يُعيد جلب sw.js (تنقّل / تحديث قسريّ / فحص دوريّ / ~24 ساعة) اليوم: لا فحص دوريّ → تبويب مفتوح لا يلاحظ النشر ← أيقونة الخريطة لا تظهر الحلّ: prompt + registration.update() كل 60ث وعند التركيز + تدقيق CDN
