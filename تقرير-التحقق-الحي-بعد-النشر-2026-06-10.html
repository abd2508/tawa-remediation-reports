6) دليل الكود من حزم الإنتاج المنشورة

فحصتُ ملفّات JS الحيّة التي يخدمها الخادم مباشرةً للتأكّد أن ما يجري على الإنتاج هو بناؤنا الجديد، لا نسخة قديمة:

// نُفِّذ داخل المتصفّح على tawanow.com — جلب /assets/config-*.js و money-*.js الحيّين
{
  i18n_conversations_subtitle (عربي) : true,   // «محادثات العملاء والسائقين أثناء التوصيل»
  i18n_table_fine_due        (عربي) : true,   // «الغرامة المستحقّة» — مفتاح ops.table الجديد
  i18n_common_creating       (عربي) : true,   // «جارٍ الإنشاء» — common.creating الجديد
  i18n_common_refresh        (عربي) : true,   // «تحديث» — common.refresh الجديد
  i18n_en_conversations    (إنجليزي): true,   // «Customer↔driver chats during delivery»
  i18n_fr_conversations    (فرنسي) : true,   // «consultation uniquement»
  money_currency_label_dl           : true    // «د.ل» في حزمة المال
}
لماذا هذا قاطع: هذه النصوص الحرفية أضفتُها في هذه الجلسة (المرحلة 1) ولم تكن موجودة قبلها. وجودها في حزم JS التي يخدمها الإنتاج الآن يثبت أن النشر فعّال وأن البناء الجديد حيّ — بما في ذلك الترجمتان الإنجليزية والفرنسية اللتان كتبتُهما يدويًّا.
