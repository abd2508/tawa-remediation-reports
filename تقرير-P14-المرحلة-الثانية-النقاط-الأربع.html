P14-8 — مؤشر المجموعة في سجل الطلبات

كانت tawa_group_map تُحفظ في localStorage عند كل نجاح جماعي، لكن صفحة سجل الطلبات لا تقرأها أبداً. أضفنا خريطة عكسية واستخدمناها لعرض Chip على كل طلب يخص مجموعة.

كيف يعمل؟

الكود المُضاف في OrderHistoryPage

// P14-8: reverse lookup { orderId → groupId } — guarded for private browsing
const groupByOrderId = useMemo<Record<string, string>>(() => {
  try {
    const raw = localStorage.getItem("tawa_group_map");
    if (!raw) return {};
    const map: Record<string, string[]> = JSON.parse(raw);
    const reverse: Record<string, string> = {};
    for (const [gid, oids] of Object.entries(map)) {
      for (const oid of oids) reverse[oid] = gid;
    }
    return reverse;
  } catch { return {}; }  // private browsing / quota errors → silent
}, []);
ملاحظة مهمة حول المصدر:

المؤشر يعتمد على localStorage فقط (لا يحتاج تغييراً في الـ backend). بمعنى: إذا سجّل الدخول من جهاز آخر، لن يرى المؤشر. هذا قرار معماري مقصود — الخلفية لا تُعيد cart_group_id في API الطلبات الفردية حالياً. إذا أراد المشغّل إظهار المؤشر لجميع الأجهزة، يحتاج تغيير backend وهو خارج الحدود الحالية.
