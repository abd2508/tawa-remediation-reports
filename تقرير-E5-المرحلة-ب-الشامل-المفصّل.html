① الخلاصة التنفيذيّة

نفّذت المرحلة ب من E5: ملأت نقطة التفعيل _run_vendor التي تركتها المرحلة أ خاملة، بـمُحوِّل مدمج ذاتيّ الاستضافة (vendor="local") يقرأ صورة الوثيقة المخزّنة من MinIO ويُقيّم سلامتها وجودتها داخل العمليّة بالكامل — بلا نداء خارجيّ، بلا مفتاح API، ولا تغادر أيّ صورة المنصّة (فلا حاجة لبوّابة خصوصيّة). نُشِر حيًّا على tawanow.com وتُحقِّق بالصور، ثمّ أُعيد كلّ شيء لحالته السابقة.

② القرار الحاكم — لماذا «محلّيّ» لا «خارجيّ»

المرحلة ب لها تشعّب حقيقيّ، وطبّقت القرار الموصى به المنضبط بقيود المشروع:

المسارقابليّة البناء هناالقرار
مزوّد خارجيّ (Incode/Paravision) — كشف انتحال/liveness بالـML غير قابل — يحتاج اختيار مزوّد + اعتمادات + اجتياز بوّابة الخصوصيّة (يُرسل صور الهويّة خارج المنصّة) يبقى خطوة مشغّل مستقبليّة (_run_vendor ما زال يرفع لأيّ اسم غير local)
مدمج محلّيّ (هذه المرحلة) — سلامة/جودة الصورة داخل المنصّة قابل — بلا نداء خارجيّ، بلا مفتاح، بلا مغادرة الصورة ⇒ لا بوّابة خصوصيّة نُفِّذ — على نمط الخرائط الذاتيّة §385 (ذاتيّ الاستضافة، fail-open، يُفعّله المشغّل)
نطاق صادق (لا «مسرح أمنيّ»): المُحوِّل المحلّيّ يفحص أنّ صورة الوثيقة قابلة للجلب + صورة صحيحة + بدقّة/حجم كافٍ — إشارة استشاريّة حقيقيّة متواضعة تلتقط الرفع المفقود/التالف/الفارغ/الصغير/بصيغة خاطئة. وهو ليس كشف انتحال/liveness/مطابقة وجه — وهذا مُوثَّق صراحةً في كود الخدمة وفي هذا التقرير.

أ — قراءة الكائن من MinIO (fail-open)

def _fetch_object_bytes(object_key) -> Optional[bytes]:
    try:
        from minio import Minio
        client = Minio(_MINIO_ENDPOINT, access_key=..., secret_key=..., secure=_MINIO_SECURE)
        resp = client.get_object(_MINIO_BUCKET, object_key)   # bucket = kyc-documents
        try:    return resp.read(_MAX_READ)               # 6 MiB حدّ ذاكرة
        finally: resp.close(); resp.release_conn()
    except Exception:                                     # كائن مفقود/غير مقروء لا يرفع أبدًا
        return None

def image_meta(data) -> (kind, width, height):
    # PNG: توقيع 8 بايت ثمّ IHDR بأبعاد big-endian
    if data[:8] == b"\x89PNG\r\n\x1a\n" and data[12:16] == b"IHDR":
        return ("png", int.from_bytes(data[16:20],"big"), int.from_bytes(data[20:24],"big"))
    # JPEG: المشي على مقاطع العلامات حتى أوّل SOFn لقراءة الارتفاع/العرض
    if data[:2] == b"\xff\xd8":
        ... walk markers; at SOF: h=data[i+5:i+7], w=data[i+7:i+9] ...
    # تمييز webp / gif / pdf بالبايتات السحريّة
    if data[:4]==b"RIFF" and data[8:12]==b"WEBP": return ("webp", None, None)
    if data[:6] in (b"GIF87a",b"GIF89a"):     return ("gif", None, None)
    if data[:5]==b"%PDF-":                       return ("pdf", None, None)
    return (None, None, None)

⑪ التحقّق الحيّ بالصور — الشارة في الواجهة

لإظهار الدرجة في الواجهة فعليًّا فُعِّل المُحوِّل مؤقّتًا عبر ملفّ override رمَويّ على المضيف (/tmp/dvb.yml يحوي DOC_VERIFY_VENDOR: local)، وإعادة إنشاء الحاوية بلا إعادة بناء وبلا مساس بملفّ الإعداد القانونيّ (docker-compose.staging.yml). بعد التفعيل (is_enabled=True) أُضيفت وثيقتان تشيران للصورتين الحقيقيّتين عبر درج وثائق مندوب اختباريّ:

ب — السلامة

  • القلب الماليّ: لا مساس — هويّة لا مال؛ FIN-COR PASS.
