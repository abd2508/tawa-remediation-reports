WP5 — nginx الديناميكيّ (لا 502 بعد إعادة البناء) مُنفَّذ + nginx -t

🟦 بلغة بسيطة: كان nginx يتذكّر العنوان القديم للخلفية بعد إعادة بنائها فيُرجِع 502. الآن يسأل عن العنوان الجديد لحظيّاً. الأهمّ: الإصلاح في الخطّة الأولى كان مكسوراً (كان سيُرسِل بادئة /api للخلفية = 404)؛ طبّقتُ المقطع المُصحَّح.
// قبل (ثابت — 502 بعد إعادة البناء): proxy_pass http://backend-core:8000/; // بعد (مُصحَّح): resolver 127.0.0.11 valid=10s ipv6=off; # DNS المدمج لـDocker location /api/ { set $api_upstream http://backend-core:8000; rewrite ^/api/(.*)$ /$1 break; # /api/foo -> /foo (تجريد البادئة يدويّاً) proxy_pass $api_upstream; } location /api/sse/ { ... rewrite ^/api/(sse/.*)$ /$1 break; ... } # /api/sse/x -> /sse/x

التحقّق: docker run nginx:1.27 nginx -t → «syntax is ok ... test is successful». توجيهات SSE الستّ محفوظة. (داخل nginx.conf فقط — لا يلمس docker-compose.yml المحظور.)
