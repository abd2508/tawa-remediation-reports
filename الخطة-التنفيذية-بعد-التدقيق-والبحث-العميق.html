③ إطار الحوكمة — كيف تُقرأ الخطّة

كلّ بند مُصنَّف ببوّابة الإذن المطلوبة، لأنّ نموذج المشروع phase-gated ولا يُكسَر القلب الماليّ. الترتيب من الأكثر أمانًا إلى الأكثر حساسيّة:

A واجهة آمنة — web/src فقط، بلا خلفيّة/migration/مال B خلفيّة غير ماليّة — إظهار بيانات (تجاوز منطقة محظورة، بلا ledger/migration) C ماليّ/أمنيّ — يحتاج إذن مالك + مراجعة FIN-COR D يحتاج migration (عمود/جدول جديد) E جوّال — منطقة محظورة، يحتاج إذن المالك F استراتيجيّ — خلف بوّابة إطلاق (قرار مالك/أعمال)
قاعدة ثابتة محترَمة: لا أكسر ختم production_payment_enabled / wallet_cash_out / wallet_peer_transfer (مُجمَّدة بـSHA في FIN-COR). لا migration ولا تعديل خلفيّة/جوّال دون إذنك الصريح. هذه الوثيقة خطّة للمراجعة فقط — لم يُنفَّذ أيّ سطر.

⑤ أحدث التقنيّات (2024–2026) — ماذا نضيف للمشروع

بحث إنترنت مؤرَّخ ومُتحقَّق، مربوط بفجوات تووا الفعليّة. الأولويّة للقابل للتطبيق في سياق ليبيا (دفع نقديّ غالب، دراجات ناريّة، FastAPI/React/Flutter).

T1 — فتح المدفوعات: مسار ليبيا الواقعيّ (يعالج A-1، أكبر فرصة)

اكتشاف مهمّ: عقوبات ليبيا (OFAC) موجَّهة لكيانات لا شاملة للبلد — فبعض المسارات تعمل قانونيًّا. أمّا Stripe/Adyen/Paymob/PayTabs/Tap فلا تغطّي ليبيا عمليًّا. لا تبنِ على بوّابات عالميّة محجوبة.
الخياريعمل في ليبيا اليوم؟الربط بتووا
Plutu (مُجمِّع)✅ نعم — REST API موثّقنقطة تكامل واحدة تجمع SADAD + بطاقات Nomu البنكيّة + T-Lync + Adfali. أسرع طريق لفتح production_payment_enabled.
SADAD (المدار) عبر Plutu✅ نعمأسرع شحن رقميّ لمشتركي المدار (محفظة OTP).
بطاقات بنكيّة ليبيّة (Nomu/Moamalat)✅ نعم (مفروضة وطنيًّا)الأوسع للمصرفيّين (~40%).
Mastercard MPGS (عبر مصرف الأمان)✅ نعمبطاقات دوليّة — حرجة لشريحة الوافدين/الزوّار (en/fr).
LYPay (مصرف ليبيا المركزيّ)🟡 أُطلق 6/2025؛ وصول الـFinTech «قريبًا»شحن بـQR عبر أيّ بنك مشارك — سجّل اهتمامًا مبكرًا.
تحويل COD → رصيد محفظة✅ نعم — صفر بنية تحتيّةعند تسليم طلب نقديّ: «احتفظ بـX كرصيد تووا؟» — يحوّل الكاش المُحصَّل أصلًا لرصيد بلا أيّ PSP. تووا تملك البنية المحاسبيّة لذلك.
