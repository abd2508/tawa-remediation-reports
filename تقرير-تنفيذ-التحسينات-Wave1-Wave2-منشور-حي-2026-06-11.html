٢. التحسينات الأربعة بالتفصيل

E4 — فرز طابور الاعتماد (KYC) حسب المخاطر خلفية + واجهة

الفكرة: ترتيب الطلبات المعلَّقة بحيث يظهر الأقلّ ثقةً أولًا (أعلى مخاطرة)، مع شارة مخاطر ملوّنة بجانب كلّ طلب — ليبدأ المراجِع بالأخطر.

E2 — تسوية ثلاثيّة لعوائم المندوبين (Agent-Float) خلفية

الفكرة: يجب أن يساوي العائم الجاري لأيّ نقطة تسوية فعّالة = (النقد الوارد عبر معاملاتها المسوّاة) − (ما سلّمته للمركز). أيّ فرق = استثناء تسوية جديد AGENT_FLOAT_MISMATCH.

الملفّالتغيير
finance/reconciliation_service.pyفحص رابع داخل run_reconciliation قبل flush() — يجمع نقد المعاملات SETTLED من قناتَي CASH/FULL، ويطرح تسليمات AGENT_FLOAT_SETTLE، ويقارن المتوقَّع بـcurrent_float_minor لكلّ مندوب فعّال.
# المعادلة المحاسبيّة الحيّة
expected = Σ(SettlementTransaction.cash_minor   # SETTLED + CASH/FULL)
         − Σ(CashHandover.amount_minor          # proof_type = AGENT_FLOAT_SETTLE)
if expected != agent.current_float_minor:
    → ReconciliationException(type="AGENT_FLOAT_MISMATCH", severity="HIGH", …)
🔑 بلا migration: عمود ReconciliationException.type لا يحمل قيد CHECK، فإضافة نوع جديد لا تتطلّب ترحيلًا — درس متكرّر في المشروع. الحارس ضدّ التكرار (_open_exc) يمنع ازدواج الاستثناء عند إعادة التشغيل (idempotent).

E1 — سياج جغرافيّ للتسوية (وضع ليّن) خلفية

الفكرة: عند تحقّق المندوب من معاملة بعيدة جغرافيًّا عن نقطته، نضع علامة استشاريّة ونطلق تنبيهًا — دون حجب التحقّق.

الملفّالتغيير
app/config.pyإعداد جديد settlement_geofence_alert_km: float = 0 — 0 = معطّل افتراضيًّا (سلوك محفوظ، fail-open عند غياب الإحداثيات).
modules/settlement/service.py · agent_verifyكتلة سياج ليّنة مشروطة بـsettlement_geofence_alert_km > 0؛ تحسب المسافة بـhaversine_meters؛ إن تجاوزت العتبة تُلحق GEO_FAR {km}km بالملاحظات + تنبيه settlement.geofence_far (best-effort)، داخل try/except — استشاريّ لا يكسر التحقّق أبدًا.

الحالة الحيّة: مُنشَر لكن خامل — لأنّ العتبة 0 افتراضيًّا؛ يُفعَّل بإعداد عند الحاجة دون إعادة نشر.

E6 — لوحة أوامر ⌘K للانتقال السريع واجهة (الموجة 2)

الفكرة: لوحة انتقال خفيفة بلا أيّ تبعية خارجيّة تُفتح بـ⌘K / Ctrl+K، تعرض فقط الوجهات المسموحة لدور المستخدم، مع فلترة فوريّة وتنقّل بالأسهم/Enter وإغلاق بـEsc.

الملفّالدور
