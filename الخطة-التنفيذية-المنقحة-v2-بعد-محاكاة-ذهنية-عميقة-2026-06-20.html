٢ التصحيح الجوهريّ — الدماغ «ظلّ» لا «حاكم» على المال

أخطر اكتشاف: مفصل احتيال COD يحجب طلب العميل فعلًا عند تفعيله. فلا يجوز أن يقرّر الدماغ الحجب. الحلّ: القاعدة تبقى الحاكم؛ الدماغ يراقب «في الظلّ» ويُسجِّل رأيه للمقارنة فقط.
القاعدة الذهبيّة المنقّحة: أيّ مفصل يؤثّر على قرار حيّ (COD-حجب، التوزيع الحيّ) ⇒ الدماغ فيه ظلّ غير متزامن دائمًا (لا يحجب، لا يبطئ). المفاصل العرضيّة فقط (لوحة مخاطر OPS، معاينة التوزيع، صحّة ETA، مساعِد OPS) ⇒ يمكن للدماغ خدمتها inline بأمان لأنّها لا تمسّ قرارًا حيًّا. هذا يصحّح C1+C2+H5 معًا.

٣ العميل والبوّابة المصحّحان (H2)

// backend/app/integrations/tic_client.py (مصحَّح: مسبح مشترك + كاش + بوّابة مخصّصة + قاطع بالذاكرة) from app.core.redis_client import _get_pool // المسبح المشترك (لا اتّصال جديد لكلّ نداء) _gate_cache = {"val": False, "exp": 0.0} // كاش 5ث في الذاكرة async def _tic_enabled() -> bool: // بوّابة مخصّصة للدماغ (لا ai_features auto-actions) now = monotonic() if now < _gate_cache["exp"]: return _gate_cache["val"] try: v = await _get_pool().get("platform:tic:enabled") // مفتاح مستقلّ val = (v == "1" or v == b"1") except Exception: val = False // fail-safe _gate_cache.update(val=val, exp=now + 5.0); return val async def score(task, payload) -> dict | None: if not settings.tic_url or not await _tic_enabled(): return None if _breaker.is_open(task): return None // قاطع بالذاكرة (لا round-trip) try: async with httpx.AsyncClient(timeout=settings.tic_timeout) as c: r = await c.post(f"{settings.tic_url}/tic/{task}", json=payload) if r.status_code != 200: _breaker.fail(task); return None _breaker.ok(task); return r.json() except (httpx.HTTPError, ValueError, KeyError, TypeError): _breaker.fail(task); return None // الاستعمال الصريح (M5): res = await tic_client.score(...); return res if res is not None else rule()

٦ الخلاصة · الخطوة الأولى الآمنة

ما تجنّبناه: لولا هذه المحاكاة لكنّا (C1) جعلنا الدماغ يحجب طلبات عملاء، (C2) بنينا «تحسين توزيع» بلا أثر، (C3) أطلقنا دماغًا لا يستطيع الكتابة، (H3) كرّرنا خطأ ازدواج النموذج. كلّها مُصحَّحة الآن.
المبدأ المنقّح: الدماغ ظلّ غير متزامن على أيّ مفصل يمسّ قرارًا حيًّا (COD/التوزيع الحيّ)، وinline آمن على المفاصل العرضيّة فقط (لوحات OPS/ETA/المساعِد). لا يحجب، لا يبطئ، لا يكتب مالًا، ولا يُفعَّل أيّ نموذج إلا بعد تفوّقه في الظلّ.
الخطوة الأولى (P0 المصحّحة): الهيكل + الصمود + الدور الهجين + البوّابة المستقلّة + هجرة التوصيات (بحارس parity) — بلا أيّ نموذج. تُثبت أنّ الدماغ يقرأ/يكتب وأنّ قطعه = صفر أثر. آمنة تمامًا خلف tic_url فارغ. ابدأ متى أذنتَ.
