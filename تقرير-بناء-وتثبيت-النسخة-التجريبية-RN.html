APK إصدار بُني بنجاح (100MB) يعمل end-to-end (محاكاة) السامسونج: غير متوافق (سبب صلب)

1) النتيجة باختصار

طلبت بناء نسخة تجريبية وتثبيتها على السامسونج. إليك ما حدث بدقّة وصدق:

  • ✅ بنيتُ نسخة إصدار حقيقية (APK قائم بذاته، يعمل بلا خادم بوضع المحاكاة).
  • ✅ أثبتُّ أنها تعمل end-to-end على جهاز Android حديث (محاكي API 30): ترحيب ← لغة ← مدينة ← هاتف ← OTP ← الصفحة الرئيسية ببيانات المتاجر.
  • ❌ تعذّر تثبيتها على السامسونج — لسبب تقني لا يمكن تجاوزه (أدناه).

2) لماذا رفض السامسونج التثبيت؟ (السبب الصلب)

رسالة النظام: INSTALL_FAILED_OLDER_SDK. تتبّع سجلّ الجهاز كشف أن إطار النظام الحقيقي للسامسونج هو Android 6.0 (API 23) — رغم أن خاصية الإصدار تُظهر «29» (روم مخصّص يزوّر الرقم).

المشكلة الجوهرية: React Native 0.86 (أحدث إصدار، Expo SDK 57) يفرض حدّاً أدنى Android 7.0 (API 24) — لأن مكتباته الأصلية الجاهزة (نواة ReactAndroid + محرّك Hermes + expo-modules-core) مبنية لـ API 24 ولا يمكن خفضها. حاولتُ إنزال الحدّ إلى 23 وإزالة مكتبة الرسوم، لكن الخطأ انتقل إلى نواة RN نفسها — فالحدّ 24 صلب في الإطار.

ملاحظة: تطبيق Flutter السابق ثُبِّت على هذا الجهاز لأن Flutter يدعم API 23. أما React Native الحديث فحدّه الأدنى 24 — وهذا فرق بين الإطارين، لا عيب في عملنا.
