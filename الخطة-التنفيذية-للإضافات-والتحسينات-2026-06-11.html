أ) شبكة المندوبين (التسوية)

E1 · جيوفنس التسوية (كشف احتيال جغرافيّ) جهد: متوسّط بلا migration

لماذا (بحث):نمط معياريّ 2025: مقارنة موقع المعاملة بموقع الطرف، وعند تجاوز عتبة المسافة → تحقّق إضافيّ (لا رفض قاطع). أين (الكود):المعاملة تلتقط lat/lng (service.py:122)، والمندوب له point_lat/lng، وثمّة geo_service.haversine_meters جاهز. نقطة الإدراج: حُرّاس agent_verify (service.py:165 بعد فحص float_cap ~227). كيف:إضافة فحص: إن توفّر موقعا المعاملة والمندوب والمسافة > عتبة (config، مثلاً 1كم) → وسم المعاملة flagged_far أو تحويلها لمراجعة OPS بدل التسوية الفوريّة. علم config افتراضيّ معطّل (سلوك محفوظ). المخاطر:ضئيلة — فحص إضافيّ خلف علم config؛ لا يكسر التدفّق الحاليّ. الاختبار:اختبارات: داخل العتبة يمرّ · خارجها يُوسَم · بلا إحداثيات يمرّ (fail-open).
المصدر: USPTO transaction-location threshold · Coris/Credolab fraud 2025

E2 · التسوية الثلاثية لعُهدة المندوب جهد: متوسّط بلا migration

لماذا (بحث):المطابقة متعدّدة المصادر + كشف الاستثناءات اللحظيّ ممارسة 2025 (Simetrik/Trintech/HighRadius). أين (الكود):خدمة المطابقة finance/reconciliation_service.run_reconciliation تُنتج استثناءات بأنواع نصّيّة (LEDGER_MISMATCH/CASH_UNACCOUNTED/SETTLEMENT_UNLINKED). العُهدة في SettlementAgent.current_float_minor؛ الحركات في SettlementTransaction + CashHandover (settle-float). كيف:إضافة فحص رابع AGENT_FLOAT_MISMATCH: لكلّ مندوب نشط، العُهدة المتوقّعة = Σ(نقد المعاملات المُسوّاة) − Σ(تسويات المركز settle-float)؛ إن خالفت current_float_minor → استثناء OPS. + بطاقة «المطابقة» في صفحة المندوبين. المخاطر:ضئيلة — قراءة فقط تُنشئ استثناءً؛ لا تحرّك مالًا. النوع نصّيّ (بلا migration). الاختبار:اختبار: مندوب متطابق=لا استثناء · مفتعَل عدم تطابق=استثناء واحد.
المصدر: Trintech/Simetrik multi-way matching 2025 · Reconwizz agent float

E3 · هيكل «المندوب الرئيس» (Master-Agent) جهد: كبير يتطلّب migration

لماذا (بحث):M-PESA: مندوبون رئيسيّون يوازنون عُهدة مندوبي التجزئة (إدارة سيولة الشبكة). أين (الكود):SettlementAgent مسطّح حاليًّا (لا هرميّة). يلزم عمود parent_agent_id (FK ذاتيّ) + نقاط «دفع عُهدة» بين الرئيس والتجزئة. كيف:migration: parent_agent_id + نقاط POST /operations/settlement-agents/{{id}}/rebalance (الرئيس يدفع/يسحب عُهدة) + عرض الشجرة. إستراتيجيّ — يُؤجَّل أو يُنفَّذ كمشروع مستقلّ. المخاطر:متوسّطة — migration + منطق مالي جديد؛ يلزم فحص FIN-COR دقيق. الاختبار:PG up/down + اختبارات إعادة التوازن + FIN-COR.
المصدر: World Bank/IFC liquidity toolkit · M-PESA master-agent
