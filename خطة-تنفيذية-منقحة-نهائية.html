هذه النتائج تأتي من قراءة مباشرة للكود — لم تكن في الخطة السابقة.

خطير feature_toggles لها صفوف بيانات

60 ترحيلاً يستخدم op.execute() بما فيها INSERTs في feature_toggles. الـ pg_dump --schema-only لا يُعيد هذه البيانات. إذا بدأت container جديدة بدون صفوف feature_toggles: split_payment_enabled وloyalty_redemption_enabled تبقى غائبة → الباكند يتصرف بشكل خاطئ.

💥 يحتاج 04_seed_feature_toggles.sql منفصل يُولَّد من DB الحية بـ pg_dump --data-only

جديد عدد الترحيلات الحقيقي: 171 (ليس 180)

العد الدقيق من ls: 171 ملف. يؤثر على تقدير وقت التشغيل: ~50-85 ثانية على DB نظيفة بدل 90.

جديد postgres: لا start_period أصلاً!

الـ healthcheck لـ postgres في docker-compose.yml لا يحتوي start_period. يُطلق الفحص فوراً على الـ container. هذا يعني أن backend قد يبدأ وpostgres لم تُنهِ initdb بعد.

جديد لا restart policy على أي خدمة

عند crash أي container (postgres, backend, redis) — تبقى ميتة إلى الأبد. يحتاج restart: unless-stopped على الثلاثة.

جديد دالتان PG خاصتان + trigger

arabic_normalize(TEXT) وcheck_journal_balanced() + trigger ledger_journal_balanced (DEFERRABLE INITIALLY DEFERRED). pg_dump يلتقطها. يجب التحقق بعد التوليد.

جديد صفر ENUM + صفر CONCURRENTLY

كل الأعمدة type/status تستخدم String+CheckConstraint (لا CREATE TYPE AS ENUM). كل الفهارس تُنشأ داخل transaction. هذا يُبسّط init.sql كثيراً — لا مشاكل ترتيب ENUM ولا CONCURRENTLY داخل initdb.

اكتشافات Multi-Device الجديدة

useCallback مستخدم فقط لـ navigateToGroup — آمن للحذف الكامل من imports.

useMemo مطلوب لأشياء أخرى — orders flat (سطر 139) + filtered (سطر 142) — يُبقى.

Redis cache يحتفظ بـ OrderSummary القديمة — يحتاج flush عند النشر.

exclude_none خطر كامن — لو كان مُفعّلاً في serialization path يُزيل group_id=null. يجب grep audit.

Explicit column SELECT خطر آخر — لو list_orders تختار أعمدة بالاسم بدل select(Order) فلن يُحمَّل group_id.

syntax القرار: str | None = None — Python 3.10+ حديث، أقصر، لا يحتاج import Optional.

entrypoint.sh المحسّن

⚠ الـ entrypoint الحالي: alembic upgrade head بدون أي حماية. مع الـ migrate service pattern الجديد، الـ entrypoint يصبح أبسط ولا يحتاج alembic.
#!/bin/sh
# backend/entrypoint.sh — Tawa Stage-2 version
# المبدأ: migrate service تتولى الترحيلات. entrypoint يبدأ uvicorn فقط.
set -e

# تحقق من متغيرات البيئة الأساسية
[ -z "$DATABASE_URL" ] && echo "[entrypoint] ERROR: DATABASE_URL not set" && exit 1
[ -z "$DATABASE_SYNC_URL" ] && echo "[entrypoint] ERROR: DATABASE_SYNC_URL not set" && exit 1

# سلامة إضافية: تحقق أن alembic_version موجود (يجب أن تكون migrate service قد انتهت)
COUNT=$(psql "$DATABASE_SYNC_URL" -tAc \
  "SELECT COUNT(*) FROM public.alembic_version" 2>/dev/null || echo 0)

if [ "$COUNT" -eq 0 ]; then
  echo "[entrypoint] WARN: alembic_version فارغ — تشغيل upgrade head احتياطياً"
  alembic upgrade head
else
  echo "[entrypoint] DB جاهزة — تخطي alembic (migrate service تولّت الأمر)"
fi

echo "[entrypoint] Starting uvicorn..."
exec uvicorn app.main:app --host 0.0.0.0 --port 8000
