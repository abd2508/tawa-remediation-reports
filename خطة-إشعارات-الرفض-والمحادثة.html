🧠 محاكاة ذهنية (سيناريو سيناريو)

مزوّد يرفض طلب محفظة: → REJECTED_BY_PROVIDER → المبلغ يُعاد فوراً (موجود) → إشعار (موجود) → بانر+اقتراحات (جديد) → العميل يختار بديلاً أو يبحث.
مزوّد يتجاهل طلب محفظة (لا يردّ): اليوم = يعلق للأبد + المبلغ محجوز 🔴 → بعد الإصلاح: الحلقة تُفعَّل بعد المهلة → REJECTED_BY_PROVIDER + إرجاع المبلغ + إشعار + بانر.
طلب نقدي مرفوض: لا مال محجوز → البانر يظهر بلا سطر استرداد (نتجنّب إرباك عميل النقد).
لا سائق: AWAITING_DRIVER → (حلقة) NO_DRIVER_ESCALATION → إشعار+بانر → «إعادة محاولة» (يعود للطابور) أو «إلغاء واسترداد» (cancel_order يُعيد المبلغ).
المحادثة: السائق يستلم (PICKED_UP) → تظهر الودجة للطرفين فوراً (SSE) → يتبادلان رسائل → عند DELIVERED تُخفى وتبقى مخزّنة → المشغّل يبحث عنها لاحقاً.
حالة حافّة — لا اقتراح مناسب: إن لم نجد بديلاً بنفس الفئة قريباً → نعرض «أبحث بنفسي» فقط (بلا اقتراح وهمي — احترام «بلا اختلاق»).
حالة حافّة — محاولة وصول غير مصرّح للمحادثة: الحارس يرفض أي شخص غير عميل الطلب/سائقه/OPS (نفس ABAC المُجرَّب).

كيف يظهر في لوحة التحكم (OPS)

  • عنصر قائمة جديد «💬 المحادثات» → صفحة: كل محادثات الطلبات مخزّنة + بحث بـ(اسم السائق · اسم العميل · رقم الطلب · الوقت · السعر · الحالة).
  • الطلبات المرفوضة/لا-سائق تظهر كما هي في «الطلبات العالقة» (موجودة) — لا تتغيّر.
