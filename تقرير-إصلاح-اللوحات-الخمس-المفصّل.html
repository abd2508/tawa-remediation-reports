③ السبب الجذريّ — .page مقابل .page-ops

/* web/src/styles/global.css */
.page      { max-width: 480px; … }   /* 768px→720px · 1100px→960px (سقف) — صفحات العميل/الجوّال */
.page-ops  { width: 100%; padding: 1.5rem 2rem; }   /* عرض كامل — لوحات OPS */
.page-ops table, .page-ops th { … }                 /* + معالجة جداول OPS */

إذًا: صفحات العميل تبقى على .page (480px للجوّال — صحيح)؛ ولوحات OPS يجب أن تكون على .page-ops (عرض كامل + جداول OPS). الـ61 لوحة OPS الأخرى كانت صحيحة بالفعل، وهذه الخمس كانت الشاذّة.
