① الخلاصة والاكتشاف

اخترتَ «⌘K لوحة أوامر OPS» (تنقّل سريع + بحث كيانات). عند التتبّع تبيّن أنّ الجزء الملاحيّ مبنيّ مسبقًا (OpsCommandPalette.tsx لوحة خفيفة بلا تبعيّة cmdk، مثبَّتة في Layout.tsx، اختصار ⌘/Ctrl+K، 8 اختبارات، منشورة). الناقص الفعليّ كان بحث الكيانات. فأكملته بإضافته لا بإعادة بناء اللوحة (للحفاظ على سلوكها واختباراتها).

③ بحث الأشخاص بالكود (في اللوحة)

// بحث مؤجَّل (300ms، ≥3 أحرف) + حارس ignore يمنع تحديث الحالة بعد الإغلاق/التفكيك
useEffect(() => {
  const q = query.trim();
  if (q.length < 3) { setPeople([]); setSearching(false); return; }
  let ignore = false; setSearching(true);
  const timer = setTimeout(async () => {
    try { const res = await operationsApi.searchUsers(q);
           if (!ignore) setPeople((res.data as PersonResult[]).slice(0, 6)); }
    catch { if (!ignore) setPeople([]); }
    finally { if (!ignore) setSearching(false); }
  }, 300);
  return () => { ignore = true; clearTimeout(timer); };
}, [query]);

// القائمة القابلة للاختيار: الملاحة أوّلًا ثمّ الأشخاص — تنقّل لوحة المفاتيح يشمل الاثنين
const items = [...navResults, ...people.map(p => ({ kind: "person", ...p }))];

الـplaceholder صار «ابحث عن صفحة أو شخص… (⌘K)». تظهر الملاحة المفلترة بالدور أوّلًا، ثمّ ترويسة «أشخاص» + صفوف المستخدمين (👤 الاسم · الهاتف · الدور).

④ تعميق الرابط + قراءة ?q

// اختيار شخص → كونسول الدور مع ?q=<phone> (مطابقة دقيقة بالهاتف)
if (c.kind === "person")
  navigate(`/ops/cp/${consoleForRole(c.role)}?q=${encodeURIComponent(c.phone)}`);
// provider→providers · driver→drivers · else→customers
// في كلّ كونسول: قراءة ?q عند التركيب فتُشغّل البحث القائم
useEffect(() => {
  const dq = new URLSearchParams(window.location.search).get("q");
  if (dq && dq.trim().length >= 3) { setPageTab("search"); handleSearch(dq.trim()); }
}, []);
⌘K← اكتب اسم/هاتف← searchUsers (debounced)← قسم «أشخاص»← اختيار← /ops/cp/{role}?q=phone← الكونسول يبدّل لتبويب البحث + بحث مسبق

⑤ عيب التبويب الذي التقطه التحقّق الحيّ

التحقّق الحيّ التقط عيبًا لم تلتقطه الاختبارات: عند تعميق الرابط لـProviders/Drivers، كان الكونسول يبقى على تبويب «⏳ بانتظار الموافقة» الافتراضيّ، فلا يُرى البحث المسبق (الإدخال والنتائج في تبويب «🔍 البحث»). الإصلاح: إضافة setPageTab("search") إلى تأثير قراءة ?q في الكونسولين (Customers بحثها ظاهر دائمًا فلا يلزمها). أُعيد البناء والنشر والتحقّق.
