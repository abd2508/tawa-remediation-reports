⑦ مقترح القرار A — أوزان VIP + الطبقات + العدالة (للاعتماد/التعديل)

درجة VIP (0–100) — مقترَح مبدئيّ

vip_score = clamp(0, 100,
      0.40 * norm(spend_90d)        // الإنفاق آخر 90 يومًا (40%)
    + 0.30 * norm(orders_90d)       // عدد الطلبات المكتملة (30%)
    + 0.20 * recency_factor         // كلّما قَرُب آخر طلب ارتفع (20%)
    + ops_manual_boost )            // تعيين غرفة العمليّات (قد يرفع لأقصى)

norm() = تطبيع نسبيّ مقابل عتبات قابلة للضبط؛ تعيين OPS اليدويّ يَجُبّ الحساب (يرفع فورًا).

الطبقات (3 طبقات — معيار عالميّ 2–4)

الطبقةالعتبة المقترَحة (قابلة للضبط)المرجع العالميّ
🥉 فضّيّدرجة ≥ 40 أو ≥ 20 طلبًا (يحافظ على السلوك الحاليّ)أعلى 20% إنفاقًا
🥈 ذهبيّدرجة ≥ 65 أو إنفاق ≥ 3× متوسّط الطلبعتبة 3–5× متوسّط الطلب (Rivo)
🥇 بلاتينيّدرجة ≥ 85 أو تعيين OPSأعلى 1–2% + تعيين يدويّ

العدالة (منع تجويع العاديّين) — إلزاميّة

  • التقادم (aging): طلب عاديّ ينتظر > vip_fairness_aging_min يُرفَع فوق VIP (تأخير محدود).
  • سقف التجاوز: لا يتجاوز VIP طلبًا عاديًّا أكثر من vip_fairness_max_skip مرّات.
  • الأولويّة عند الحِمل الخفيف فقط (إن كان الطابور مزدحمًا جدًّا تتراجع لئلّا تُجوِّع).
