تصحيح G3 — بطاقة «الكتالوج» في الرئيسية «حوّلها إلى t("provider.catalog") لإصلاح i18n + التسمية معًا». مرفوض. الداشبورد لا يستخدم t() إطلاقًا (0 استدعاء — مؤكَّد). إدخال i18n لسطر واحد وسط ملفٍ كلّه نصوص مضمّنة = توسيع نطاق غير مبرَّر. الصحيح: تغيير النصّ المضمّن «الكتالوج»→«الأصناف» فقط.
تأكيد G6 — مكان إدراج البطاقة «بعد شريط الخطأ» (تقديري). دقيق: if (loading) return <LoadingSpinner/> (سطر 80) ← ثم return (82) ← <h2> (84). تُدرَج البطاقة مباشرة بعد <h2> (سطر 84)، أعلى الصفحة.

تبرئة اختبارات e2e (Playwright) لم تُفحَص. فُحِصت كل الـspecs: لا كسر. بل تور all_fixes_tour · P-504 اسمه ووسومه تتوقّع «الأصناف» أصلًا → التسمية متّسقة معه لا معارِضة.
تبرئة تكرار خفيّ لبطاقة الدعوة لم يُنفَ صراحةً. بحث شامل: لا نسخة ثانية للبطاقة في الإعدادات أو غيرها → مصدر واحد فقط، والنقل آمن.
الخلاصة: المراجعة العميقة لم تكتفِ بإضافة فجوات، بل صحّحت خطأ في خطتي نفسها (G3) كان سيُدخل تعقيدًا لا لزوم له. هذا جوهر «الأدقّ والأعمق».
