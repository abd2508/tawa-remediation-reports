المشاكل والحلول — قبل وبعد

المشكلة 1 — لا تظهر التحديثات

Cloudflare كان يُخزَّن sw.js لـ4 ساعات. nginx لم يكن يضع Cache-Control headers. الكود يتغير على السيرفر لكن الزوار يرون النسخة القديمة.

الحل — مكتمل + إجراء فوري

nginx الآن يضع no-store على sw.js. بعد Purge من Cloudflare Dashboard، كل التحديثات تظهر فوراً. المشكلة لن تتكرر.

المشكلة 2 — السلة مقسّمة

CartContext.tsx يدعم متجراً واحداً نشطاً فقط. إضافة من متجر آخر تُعطّل السلة الأولى أو تحفظها جانباً. لا يمكن الدفع من متجرين معاً.

الحل — يحتاج موجة مستقلة

ربط CartContext بـ /carts/* API (جاهزة منذ ab03) + تحديث CheckoutPage لاستدعاء /carts/checkout-group. Backend مكتمل، فقط frontend يحتاج بناء.

المشكلة 3 — 7 مراحل بلا واجهة

المراحل P1-P18 كانت backend فقط (ab12-ab20). لا يوجد ولو زر واحد يُعبّر عنها في الواجهة. المستخدمون لا يرون أي تغيير رغم أن backend تغيّر كثيراً.
